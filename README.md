Portfolio - Patrick KUMANISA

## Description

Ce projet est un portfolio personnel développé pour présenter mon profil, mes compétences et mes réalisations en développement web.

L'objectif est de proposer une vitrine professionnelle moderne, claire et interactive permettant à un recruteur ou client de comprendre rapidement :
- Qui je suis
- Ce que je fais
- Ce que je peux apporter

---

## Objectifs du projet

- Mettre en avant mes compétences techniques
- Présenter mes projets (SaaS, E-commerce, Portfolio Personnel)
- Créer une expérience utilisateur fluide et moderne
- Convertir les visiteurs en opportunités (contact)

---

## Stack utilisée

- HTML5
- Tailwind CSS (via CDN)
- JavaScript
- AOS (Animation On Scroll)
- Formspree (gestion du formulaire)

---

## Fonctionnalités

- Hero section avec présentation claire
- Section "À propos" avec storytelling
- Showcase de projets :
  - Application SaaS
  - Boutique E-commerce
  - Portfolio institutionnel
- Formulaire de contact fonctionnel
- Liens vers GitHub et LinkedIn
- Animations modernes avec AOS
- Design responsive (Mobile First)

---
